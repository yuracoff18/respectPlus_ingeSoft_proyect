# Respect+ Frontend

Next.js App Router + React + TypeScript. Estilos CSS propios, responsive y con movimiento reducido. No requiere fuentes ni imágenes remotas.

```powershell
npm ci
npm run dev
```

Abre http://localhost:3000. La API debe ejecutarse en http://127.0.0.1:8000, o en el origen configurado con BACKEND_URL en .env.local. El proxy /api resuelve ese origen en tiempo de ejecución, también en la imagen standalone de Docker.

Consulta ../README.md para Docker, backend, funcionamiento y límites del proyecto.
